How your data is kept

Each entry is encrypted in this browser with your passphrase before it is saved. Quiet Pages stretches the passphrase with PBKDF2-SHA256, 600,000 rounds, then encrypts with AES-256-GCM through the browser's Web Crypto. Only that encrypted data is written to this browser. The passphrase is never saved. Nothing is uploaded. After the app is on this device, it works offline.

If you forget your passphrase, your entries cannot be recovered. There is no reset and no recovery. Quiet Pages cannot read them or hand them back.

A backup file is encrypted too. Opening it takes the passphrase you were using when that backup was exported. If you change the passphrase later, older backup files still need the older passphrase.

The demo keeps up to 10 entries so it stays small. That is a convenience limit, not copy protection. You can read, edit, delete, and export those entries, then import the backup into the full version.

If the journal locks while you are writing

The unsaved page is encrypted and kept on this device. The next time you unlock, that page opens again. Saving or cancelling removes the saved copy.

Install to your Home Screen

iPhone and iPad (Safari)

  1. Tap the Share button.
  2. Tap Add to Home Screen.
  3. Tap Add.

Android (Chrome)

  1. Tap the menu button.
  2. Tap Install app, or Add to Home screen.
  3. Confirm.

Desktop (Chrome or Edge)

  1. Look for the install icon in the address bar, or open the browser menu.
  2. Choose Install Quiet Pages.

Browser storage

Safari can delete stored website data, especially for a site you have not added to the Home Screen. Any browser can delete it if you clear website data. Export a backup regularly so a cleared browser is not the only copy.

Privacy

Effective date: [date placeholder]

Quiet Pages collects no personal data. It has no analytics, ads, or tracking, and it makes no network requests.

Entries are stored only on your device, in your browser's local storage (IndexedDB), encrypted. We can't see, recover, or delete your entries. There is no account and no server copy.

Backups are files you control. They stay encrypted, and reading one takes the passphrase used when that file was exported.

Quiet Pages is not directed at children under 13, and it does not knowingly collect personal information from children.
